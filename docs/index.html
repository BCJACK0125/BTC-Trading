      資料

      K 線來自 Binance 公開行情 API（OKX 備援），恐懼貪婪指數來自 alternative.me，資金費率來自 Binance／OKX 永續合約。數值已與 TradingView 上的 BINANCE:BTCUSDT 核對一致。

      更新

      GitHub Actions 在每根 4h K 線收盤後約 10–30 分鐘執行（台灣時間 0、4、8、12、16、20 點收盤；GitHub 的排程常會晚幾分鐘）。頁面上的即時價格每 15 秒直接向交易所查詢。

      通知

      狀態改變（出現進場訊號、系統進場、TP1 到價、出場）時，可以用 Email、Telegram 或 Discord 收到通知，內容和上方「現在要做的事」相同。設定方式見 README 的「推播通知」：在 GitHub repo 的 Secrets 填入帳號即可，不需要伺服器。

      限制

      回測含手續費 0.05% 與滑價 0.02%，同一根 K 線同時碰到止損與止盈時假設先止損。只做多的策略在牛市大幅落後買入持有，優勢在於避開熊市與控制回撤。即使樣本外表現穩定，過去績效不代表未來。本頁不是投資建議。
